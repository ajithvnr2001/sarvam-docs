## Your questions, answered

### What languages are supported?

Sarvam Speech to Text supports 22 Indian languages including Hindi, Bengali, Tamil, Telugu, Gujarati, Kannada, Malayalam, Marathi, Punjabi, Odia, and English (Indian accent). The API supports automatic language detection and handles code-mixed audio seamlessly.

### What is Saaras V4?

Saaras V4 is our latest speech-to-text model. It auto-detects the spoken language and transcribes across all 22 supported Indian languages plus Indian English, with five output modes (transcribe, translate, verbatim, translit, codemix) and key term prompting to bias recognition toward names, brands, or domain-specific terms. It handles code-mixed audio seamlessly and is optimized for both real-time and batch processing.

### What API types are available?

We offer three variants: REST API for files under 30 seconds with synchronous processing, Batch API for files up to 2 hours with speaker diarization and timestamps, and Streaming API for real-time transcription via WebSocket. Our Realtime Streaming API (beta) additionally supports interim transcripts, so you get partial results as the user is still speaking.

### What audio formats are supported?

We support 10+ formats including MP3, WAV, AAC, OGG, Opus, FLAC, M4A, AMR, WMA, and WebM. The Streaming API supports WAV and raw PCM formats at 16kHz sample rate.

### Does it support speaker diarization?

Yes, our Batch API supports speaker diarization for up to 20 speakers per audio file. It identifies and labels different speakers in your audio with timestamps for each segment. This is ideal for meeting transcriptions, interviews, and call center analytics where you need to know who said what.
