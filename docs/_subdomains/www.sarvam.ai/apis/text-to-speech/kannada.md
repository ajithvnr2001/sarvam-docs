### How many Kannada voices are available?

Bulbul v3 offers multiple Kannada voices with different characteristics: conversational, authoritative, warm, dynamic. Each supports pace control and temperature adjustment.

### Does it handle Kanglish code-switching?

Yes. Bulbul v3 handles natural Kannada-English code-switching seamlessly without accent shifts or unnatural pauses between languages.

### How does it handle Kannada consonant clusters?

Our context-aware phoneme model is trained specifically on Kannada consonant patterns, correctly processing complex conjunct consonants with high accuracy.

### Can I use Kannada TTS for real-time voice agents?

Yes. Our WebSocket streaming API delivers sub-250ms first byte latency for Kannada, ideal for real-time voice agents and conversational AI.

All 8 formats: MP3, WAV, AAC, OPUS, FLAC, PCM, MULAW, and ALAW. Sample rates from 8kHz to 24kHz.
