## Your questions, answered

### How many Punjabi voices are available?

Bulbul v3 offers multiple Punjabi voices with different characteristics: conversational, authoritative, warm, dynamic. Each supports pace control and temperature adjustment.

### Does it handle Punglish code-switching?

Yes. Bulbul v3 handles natural Punjabi-English code-switching seamlessly without accent shifts or unnatural pauses between languages.

### How does it handle Punjabi tonal distinctions?

Our tone-aware prosody model correctly renders Punjabi's pitch-based tonal contrasts, which change word meaning. A feature most global TTS engines miss entirely.

### Can I use Punjabi TTS for real-time voice agents?

Yes. Our WebSocket streaming API delivers sub-250ms first byte latency for Punjabi, ideal for real-time voice agents and conversational AI.

### What audio formats are supported for Punjabi TTS?

All 8 formats: MP3, WAV, AAC, OPUS, FLAC, PCM, MULAW, and ALAW. Sample rates from 8kHz to 24kHz.
