##  FAQs 

### Is there an API for English to Kannada translation?

Yes. Sarvam's Translate API supports English to Kannada translation with three style options (formal, classic colloquial, modern colloquial) and both native script and romanized output. Sign up for a free API key to get started.

### Can I translate code-mixed English input to Kannada?

Yes. Mixed-language input is first-class, not an edge case. If your users write in English mix, Sarvam understands the full sentence structure and translates it accurately to Kannada. No preprocessing required.

### Can I translate Indian English expressions to Kannada?

Yes. Sarvam understands Indian English conventions like lakh, crore, prepone, and revert back. These expressions are translated correctly into natural Kannada rather than being treated as errors.

### Can I translate entire documents from English to Kannada?

Yes. Upload PDF, DOCX, or PPTX files and get the full document translated to Kannada with formatting preserved. Available through both the API and the dashboard.

### What is the difference between Formal and Colloquial translation styles?

Formal style produces clean, professional output suitable for legal documents, official communications, and business content. Classic Colloquial uses traditional conversational language, while Modern Colloquial uses contemporary everyday speech patterns.

### Is Sarvam better than Google Translate for English to Kannada?

Sarvam is purpose-built for Indian languages. It handles code-mixed input natively, offers multiple translation styles, and translates directly between Indian languages without routing through English. For English to Kannada specifically, this means more natural, context-aware output.
