Returns every filter token declared by the board's widgets. Filters are derived from widget SQL rather than created directly, and are bounded by the board.

### Path parameters

org_idstringRequired

Organization ID

workspace_idstringRequired

Workspace ID

board_idstringRequired`format: "uuid"`

Board ID, as returned in `id` by Create board or List boards. Must be a UUID; anything else is rejected with 422.

### Headers

X-API-KeystringRequired

Your workspace API key.

### Response

Successful Response

filterslist of objects

The board's filters, in display order

Show 7 properties

Unauthorized Error

403
