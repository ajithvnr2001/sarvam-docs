Updates any of the rule’s fields. `enabled: false` pauses it and clears `next_run_at`. A rule must keep at least one delivery channel.

### Path parameters

org_idstringRequired

Organization ID

workspace_idstringRequired

Workspace ID

board_idstringRequired`format: "uuid"`

Board ID, as returned in `id` by Create board or List boards. Must be a UUID; anything else is rejected with 422.

rule_idstringRequired`format: "uuid"`

Notification rule ID (`rule_id`), from List notification rules. Must be a UUID; anything else is rejected with 422.

### Headers

X-API-KeystringRequired

Your workspace API key.

### Request

This endpoint expects an object.

namestring or nullOptional`1-80 characters`

New label

cronstring or nullOptional`>=1 character`

New five-field cron expression (`minute hour day-of-month month day-of-week`), evaluated in IST (Asia/Kolkata). It may not fire more than once an hour: `* * * * *` is rejected with 422.

enabledboolean or nullOptional

Pause or resume the schedule. Disabling clears `next_run_at`.

email_recipientslist of strings or nullOptional

Replacement recipient list. An empty list clears email delivery.

slack_webhook_urlstring or nullOptional`format: "^https://hooks\.slack\.com/"`

New slack incoming-webhook URL. Must start with `https://hooks.slack.com/`; any other URL is rejected with 422. Write-only: no endpoint ever returns it. Read `slack_configured` to tell whether one is set.

slack_channel_namestring or nullOptional`<=80 characters`

New Slack display label

### Response

Successful Response

rule_idstring`format: "uuid"`

Rule identifier, used as `{rule_id}` in nested routes

widget_idstring`format: "uuid"`

Widget whose result this rule delivers

cronstring

Five-field cron expression, evaluated in IST (Asia/Kolkata)

enabledboolean

False while the schedule is paused

created_atdatetime

Creation time, UTC, RFC 3339

updated_atdatetime

Last change time, UTC, RFC 3339

namestring or nullOptional

Label for the rule, or null when unnamed

next_run_atdatetime or nullOptional

Next scheduled delivery, in UTC. Null while the rule is disabled.

email_recipientslist of strings or nullOptional

Configured email recipients

slack_channel_namestring or nullOptional

Slack destination label, when one is configured

slack_configuredbooleanOptionalDefaults to `false`

True when a Slack webhook is set. The URL itself is never returned.
