POST

/api/evals/v1/:org_id/:workspace_id/test-suites/:test_suite_id/test-cases

Python
    
    
    import requests
    
    url = "https://apps.sarvam.ai/api/evals/v1/org_id/workspace_id/test-suites/test_suite_id/test-cases"
    
    payload = {
    
        "name": "Caller reschedules to the weekend",
    
        "category": "Rescheduling",
    
        "user_scenario": "The caller has an appointment tomorrow morning but now wants a weekend slot. They are in a hurry, switch to Hindi midway, and ask twice whether a cancellation fee applies.",
    
        "expected_behaviors": [
    
            {
    
                "name": "Offers concrete slots",
    
                "description": "Proposes at least two specific dates and times instead of asking the caller to choose blindly."
    
            },
    
            {
    
                "name": "Confirms the new booking",
    
                "description": "Repeats the final date, time and clinic name back to the caller before ending the call."
    
            }
    
        ],
    
        "variable_overrides": [
    
            {
    
                "name": "patient_name",
    
                "value": "Meera"
    
            }
    
        ],
    
        "max_turns": 30
    
    }
    
    headers = {
    
        "X-API-Key": "<your-api-key>",
    
        "Content-Type": "application/json"
    
    }
    
    response = requests.post(url, json=payload, headers=headers)
    
    print(response.json())

### Path parameters

org_idstringRequired

Organization ID

workspace_idstringRequired

Workspace ID

test_suite_idstringRequired

### Headers

X-API-KeystringRequired

Your workspace API key.

### Request

This endpoint expects an object.

namestringRequired`1-255 characters`

categorystringRequired`1-255 characters`

user_scenariostringRequired`1-20000 characters`

What the simulated user is trying to do.

expected_behaviorslist of objectsOptionalDefaults to `[]`

Behaviors the agent is graded against.

Show 2 properties

variable_overrideslist of objectsOptionalDefaults to `[]`

Suite variables overridden for this test case only.

Show 2 properties

max_turnsintegerOptional`1-200`Defaults to `50`
