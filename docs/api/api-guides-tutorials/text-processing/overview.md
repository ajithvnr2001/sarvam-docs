This page is for Model APIs.

Sarvam AI offers text translation and transliteration models for short text. For whole documents (PDF, Word, and more), use the [Document Translation API](https://docs.sarvam.ai/api/api-guides-tutorials/doc-translation/overview).

[Sarvam-TranslateTranslation model that supports all 22 official Indian languages and is optimized for structured, long-form text.](https://docs.sarvam.ai/api/getting-started/models/sarvam-translate)

[MayuraAdvanced text processing model with translation, transliteration, and script conversion capabilities for Indian languages.](https://docs.sarvam.ai/api/getting-started/models/mayura)

Use the [Sarvam translate skill](https://github.com/sarvamai/skills/tree/main/translate) to generate correct translation code from your AI coding assistant:
    
    
    npx skills add sarvamai/skills --skill translate

See [Agent Skills](https://docs.sarvam.ai/api/developer-tools/agent-skills) for the full list.

## Sarvam-Translate

Sarvam Translate enables high-quality translation between English and 22 scheduled Indian languages and is optimized for structured, long-form text.

## Text Processing Features

###### Basic Translation

###### Advanced Options

### Basic Text Translation

Translate structured, long-form text between Indian languages. Features include:

  * Support for all 22 scheduled Indian languages
  * Formal Style Translation
  * Numeral Format Control between international and native numeral systems



PythonJavaScriptcURL
    
    
    from sarvamai import SarvamAI
    
    client = SarvamAI(api_subscription_key="YOUR_SARVAM_API_KEY")
    
    response = client.text.translate(
    
        input="भारत एक महान देश है। इसकी संस्कृति बहुत पुरानी और समृद्ध है।",
    
        source_language_code="hi-IN",
    
        target_language_code="gu-IN",
    
        model="sarvam-translate:v1"
    
    )
    
    print(response)

Check out our detailed [API Reference](https://docs.sarvam.ai/api-reference/text/translate-text) to explore Translation and all available options.

## Mayura: Our Text Processing Model

Mayura is our state-of-the-art text processing model that excels in handling Indian languages with features like translation, transliteration, and script conversion.

## Text Processing Features

###### Basic Translation

###### Advanced Options

### Basic Text Translation

Translate text between Indian languages with high accuracy. Features include:

  * Support for multiple Indian languages
  * Automatic language detection
  * Natural and fluent translations
  * Context-aware processing



PythonJavaScriptcURL
    
    
    from sarvamai import SarvamAI
    
    client = SarvamAI(
    
        api_subscription_key="YOUR_SARVAM_API_KEY",
    
    )
    
    response = client.text.translate(
    
        input="Hello, how are you?",
    
        source_language_code="auto",
    
        target_language_code="hi-IN",
    
        speaker_gender="Male"
    
    )
    
    print(response)

Key Considerations

  * Maximum text length: 1000 characters per request (`mayura:v1`) / 2000 characters per request (`sarvam-translate:v1`)
  * Supports 10 Indic Languages and English
  * Automatic language detection available
  * Translation modes: formal (default), modern-colloquial, classic-colloquial, code-mixed



## Limits

Limit| Value  
---|---  
Translate: max input length| 1,000 characters (`mayura:v1`) / 2,000 characters (`sarvam-translate:v1`)  
Transliterate: max input length| 1,000 characters per request  
Rate limits| See [Rate Limits](https://docs.sarvam.ai/api/getting-started/ratelimits)
