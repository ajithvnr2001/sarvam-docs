# [Change Log](https://docs.sarvam.ai/changelog)

[June 1, 2025](https://docs.sarvam.ai/changelog/2025/6/1)

[June 1, 2025](https://docs.sarvam.ai/changelog/2025/6/1)

## Sarvam-Translate Launched

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

Released `sarvam-translate:v1`, an open-weights model supporting 22 Indian languages.

## Text Quickstart Updated

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

Added `sarvam-translate` usage examples to the Python SDK Quickstart and Playground.

## Real-Time STT via WebSocket

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

Added WebSocket support for live transcription with ultra-low latency in both Python and JavaScript SDKs.

## STT Input Audio Formats Expanded

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

STT now accepts `mp3`, `wav`, `aac`, `aiff`, `ogg/opus`, `flac`, `mp4/m4a`, and `amr` input formats.

## Batch STT (Alpha)

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

Introduced alpha support for batch transcription in Python SDK. Install via `pip install sarvamai==0.1.11a2`.

## Saaras & Saarika WebSocket Support

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

Both `saaras` and `saarika` models now support real-time streaming via WebSocket.

## Real-Time TTS Streaming

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

Generate speech on the fly using WebSocket streaming. Available in Python and JavaScript SDKs.

## TTS Output Audio Formats Expanded

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

TTS now outputs in `mp3`, `linear16`, `mulaw`, `alaw`, `opus`, `flac`, `aac`, and `wav`.

## Python SDK v4.23.2

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

Includes real-time streaming support, batch transcription (alpha), new translation APIs, and model updates.

## JavaScript SDK Updated

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

Added real-time STT & TTS WebSocket support and updated documentation with streaming quickstarts.

## Sarvam-M Model Added

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

Introduced `sarvam-m` to the model family.

## Saarika and Saaras Updated to v2.5

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

`saarika` and `saaras` updated to `v2.5` with character limit improvements and stability enhancements.

## Cookbooks Expanded

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

Added examples for `sarvam-translate`, updated LID and chat completion cookbooks, updated with the SDK package and refreshed starter notebooks.

## AI-Powered Docs Assistant

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

Added an AI assistant to the documentation search bar for instant Q&A and developer support.

## Usage Analytics Dashboard

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

Released real-time API usage and credit tracking at [dashboard.sarvam.ai/usage](https://dashboard.sarvam.ai/usage).
