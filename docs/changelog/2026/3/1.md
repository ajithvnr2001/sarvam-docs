## Removed Gemma Models

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

Removed the Gemma model IDs from the `SarvamModelIds` enum. These are no longer accepted values for the `model` parameter on the Chat Completions API.

## Removed Wiki Grounding

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

Wiki grounding is no longer supported for `sarvam-30b` and `sarvam-105b`. Requests that previously enabled grounding on these models should drop the parameter.

## Chat Completions in SDKs

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

Added Chat Completions (LLM) support to the Python and TypeScript SDKs, so you can call the chat API through a typed client instead of raw HTTP requests.

## Pronunciation Dictionary v2

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

Added pronunciation dictionary v2, giving you finer control over how specific words and names are transcribed.

## Document Digitization Page Limit and Pricing

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

Introduced a 10-page-per-request limit and updated pricing to ₹1.5/page. Split larger documents into 10-page batches to stay within the limit.
