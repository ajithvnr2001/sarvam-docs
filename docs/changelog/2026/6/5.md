## Sarvam-M Deprecated

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

`sarvam-m` has been deprecated and is no longer accepted by the Chat Completions API - requests that pass `model="sarvam-m"` will fail. The supported chat models are now `sarvam-30b` (64K context) and `sarvam-105b` (128K context). Existing integrations should migrate to [Sarvam-30B](https://docs.sarvam.ai/api/getting-started/models/sarvam-30b) or [Sarvam-105B](https://docs.sarvam.ai/api/getting-started/models/sarvam-105b) for better quality and longer context.
