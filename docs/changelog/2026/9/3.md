## `saaras:v4` on the Realtime API

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

`saaras:v4` is now available on the [Realtime API](https://docs.sarvam.ai/api/api-guides-tutorials/speech-to-text/realtime-streaming) alongside `saaras:v3-realtime`, with the same connection parameters and message protocol. `saaras:v3-realtime` remains the default.
