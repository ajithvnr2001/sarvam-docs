## Per-Language Voice Selection

[Voice Agents](https://docs.sarvam.ai/changelog?filter=Voice%20Agents)

Assign a dedicated Text-to-Speech voice persona to each starting language directly from the agent’s [Voice settings](https://docs.sarvam.ai/voice-agents/build/voice-language), replacing the need for hardcoded voice configuration. Enable **Per-language voices** (_Overrides default voice_) and define a conditional mapping for each language — for example, `Mansi` for Hindi, `Cynthia` for Odia, or `Arjun Bhatt` for English. At the start of a call, the agent selects the voice persona assigned to the [starting language](https://docs.sarvam.ai/voice-agents/build/conversation-settings#language-personalisation). The assigned speaker then remains consistent for the duration of the call, even if the caller switches languages mid-conversation.

## Voice Lifecycle API

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

The voice library is now manageable over the API - no Studio visit required. `POST /voices/create` creates a cloned voice from a reference clip in one shot: the response returns the new `voice_id` and the auto-generated transcript (`reference_text`) together, and the voice is immediately usable with `POST /voices/clone`. `GET /voices` lists your voices, `GET /voices/{voice_id}` returns details with time-limited signed audio URLs, and `DELETE /voices/delete/{voice_id}` deletes a voice (freeing a slot against your tier’s voice cap). See [Manage saved voices](https://docs.sarvam.ai/api/api-guides-tutorials/voice-cloning/overview#manage-saved-voices) and the [API Reference](https://docs.sarvam.ai/api-reference/voice-cloning).

## Keyterm Prompting for Saaras v4

[Model APIs](https://docs.sarvam.ai/changelog?filter=Model%20APIs)

Added [Keyterm Prompting](https://docs.sarvam.ai/api/api-guides-tutorials/speech-to-text/how-to/keyterms) support for `saaras:v4` on the REST and Batch APIs. Pass a JSON list of up to 50 domain-specific names, places, brands, or technical terms under `keyterms` to bias recognition toward them.
