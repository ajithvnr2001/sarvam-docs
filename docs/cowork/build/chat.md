# Chat

Ask a question|Copy page|[View as Markdown](https://docs.sarvam.ai/cowork/build/chat.md "View this page as plain text")|More actions

This page is for Cowork.

**Chat** is for ad-hoc tasks. Type a task into the prompt bar and get an immediate response: answers, drafted documents, summaries, or step-by-step analysis.

You can attach files and images directly to your message for context: drop in a PDF to summarise, a spreadsheet to analyse, an image to describe, or a document to draft from. Every session keeps context, so you can build on earlier messages without re-explaining.

**Great for:** one-off tasks, brainstorming, drafting, quick lookups, or trying out an idea before turning it into a reusable agent.

If you find yourself running the same task again and again, turn it into an agent. See [Create custom agents](https://docs.sarvam.ai/cowork/build/creating-an-agent).
