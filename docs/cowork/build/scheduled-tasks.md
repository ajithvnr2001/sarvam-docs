# Scheduled Tasks

Ask a question|Copy page|[View as Markdown](https://docs.sarvam.ai/cowork/build/scheduled-tasks.md "View this page as plain text")|More actions

This page is for Cowork.

**Scheduled Tasks** let an agent run automatically on a repeating schedule or once at a set time. Point a schedule at an agent, choose when it should run, and the work is done before you need it: daily briefings, weekly reports, periodic inbox triage.

![Cowork Scheduled tasks empty state reading 'Schedule your first task', with 'Set up manually', 'Create with AI', and 'New task' options.](https://docs.sarvam.ai/_fern-img/3f7c1f347367ebc5252f084273639bc114c59cb5a4e04548e7407db678a7aea3.webp)

Scheduled Tasks: point a schedule at an agent and the work is done before you need it.

## Set up a task

You can **set up a task manually** by choosing the agent and when it should run, or **create it with AI** by describing the schedule in plain language. You can also just tell an agent to schedule a task in conversation, and it sets up the schedule for you. Either way the agent runs on its own from then on.

**Great for:** recurring work with a natural rhythm that does not need to be triggered manually each time.
