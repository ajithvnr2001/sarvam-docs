# Email triage

Ask a question|Copy page|[View as Markdown](https://docs.sarvam.ai/cowork/use-cases/email-triage.md "View this page as plain text")|More actions

This page is for Cowork.

Draft and send email without living in your inbox. With a Gmail connector, an agent can read a thread, draft a reply in your voice, and send it. Pair it with a schedule to triage your inbox every morning.

## What it uses

Piece| Role  
---|---  
[Connectors](https://docs.sarvam.ai/cowork/build/connectors)| Gmail, to read threads and send replies  
[Skills](https://docs.sarvam.ai/cowork/build/skills)| Your reply style and triage rules, applied consistently  
[Scheduled Tasks](https://docs.sarvam.ai/cowork/build/scheduled-tasks)| Run the triage every morning on its own  
  
## How to build it

  1. Add and authorise the **Gmail** connector.
  2. Create an agent whose instructions describe how to triage and reply in your voice.
  3. Test it in the playground on a few real threads.
  4. Point a **Scheduled Task** at it so it runs each morning.
