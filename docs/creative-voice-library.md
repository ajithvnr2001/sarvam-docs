# Voice Library

Ask a question|Copy page|[View as Markdown](https://docs.sarvam.ai/creative-voice-library.md "View this page as plain text")|More actions

This page is for Content Studio.

The Voice Library is where Sarvam’s catalog of ready-made AI voices lives, alongside any voices you’ve cloned yourself. It’s the persona source both Text to Speech and Dubbing draw from, and functions as the single source of truth for a project’s voice.

## Popular Use Cases

  * Previewing a voice’s tone and accent before committing it to a project.
  * Keeping a consistent narrator persona across multiple Text to Speech or Dubbing projects.
  * Browsing curated voice pairings by content type - e.g. audiobook narrators or two-host podcast pairs - for inspiration before picking your own.



## Persona Carryover

A voice selected here carries over directly into Text to Speech and Dubbing’s voice-selection steps - you don’t need to re-select it in each tool.
