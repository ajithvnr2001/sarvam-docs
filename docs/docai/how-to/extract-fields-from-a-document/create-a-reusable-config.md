# Create a Config

Ask a question|Copy page|[View as Markdown](https://docs.sarvam.ai/docai/how-to/extract-fields-from-a-document/create-a-reusable-config.md "View this page as plain text")|More actions

This page is for Doc Agents.

A **Config** is a saved recipe: a name, a description of what you want to extract or digitise, a language or output format, and any sharing settings. Build once, re-run against every document of that type.

There are four ways to create a Config. Pick the one that fits your situation.

###### Way 1: Save configuration used on your project

###### Way 2: Start from a template

###### Way 3: Duplicate an existing Config

###### Way 4: Build a custom Config

Already ran an Extract project and happy with the results? Save the configuration directly from the project — no need to rebuild the schema from scratch.

[1](https://docs.sarvam.ai/docai/how-to/extract-fields-from-a-document/create-a-reusable-config#start-an-extract-project)

### Start an Extract project

In the [Doc Agents](https://docs.sarvam.ai/docai/getting-started/overview) dashboard at [indus.sarvam.ai](https://indus.sarvam.ai/akshar/dashboard), upload a document, describe what you want to extract, and run the project.

![Doc Agents Extract project setup showing a document upload and an extraction prompt describing the fields to extract.](https://docs.sarvam.ai/_fern-img/158cdd21708730e59e9489fa5dcd97f9b3859e0c7a88ebcc9b18065be26d2979.webp)

Start an Extract project: upload a document and describe what you want to extract.

[2](https://docs.sarvam.ai/docai/how-to/extract-fields-from-a-document/create-a-reusable-config#open-the-config-tab)

### Open the Config tab

Once the project finishes processing, open it and switch to the **Config** tab. Here you can play around with the schema — add or remove fields, change types, adjust descriptions — until the extracted output matches what you need.

![Doc Agents project view with the Config tab open, showing the schema editor where fields can be added, removed, and their types and descriptions adjusted.](https://docs.sarvam.ai/_fern-img/66f5b91f88ef63d675964a4b75d8b1a01cfd0ac426b17b59705fa1791420b42b.webp)

Open the processed project and switch to the Config tab to refine the extraction schema.

[3](https://docs.sarvam.ai/docai/how-to/extract-fields-from-a-document/create-a-reusable-config#save-the-configuration)

### Save the configuration

When you’re satisfied with the schema, click **Save** to save the configuration. The Config appears under **Your configs** for reuse.

## Where Configs live

Configs live under **Workspace → Configs** in the sidebar. The page has two tabs:

  * **Your configs.** Anything your workspace has built or duplicated.
  * **Templates.** The 12 shipped templates. Filter by **All / Extract / Digitise** using the pills.



![Your configs tab showing the workspace's saved Configs with Operation, Usage, and Last used columns.](https://docs.sarvam.ai/_fern-img/593646629b79d39c7c8766bc34fe011455996cfd5665adc198bb1022d24fdd27.webp)

Your configs: the recipes your workspace has built or duplicated.

![Configs page with Your configs and Templates tabs, All / Extract / Digitise filter pills, and a Usage column.](https://docs.sarvam.ai/_fern-img/3309ddeaf1ba15e24c196353bbb5200c6b49bed01871aeac05b44c0c592501ee.webp)

Workspace → Configs: Your configs and Templates tabs, with All / Extract / Digitise filter pills and a Usage column.

Each row shows a `Usage` count (how many projects have used the Config) and a `Last used` timestamp, a quick signal for which recipes your team relies on.
